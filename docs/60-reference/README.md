## Why `routes.md` is the odd one out

It is the only **derived** document in the library. Everything else here is hand-written
and dated.

A derived document is generated from the tree and **never hand-edited** — regenerating is
the only way to change it. That makes it structurally incapable of the defect the rest of
this library guards against: it cannot be *wrong*, only *stale*, and staleness is
detectable by regenerating.

```bash
node scripts/_routes_doc.cjs            # regenerate
node scripts/_routes_doc.cjs --check    # exit 1 if stale
```

**The `--check` mode was negative-controlled**: perturbing a row in the generated file
makes it exit 1, and restoring the file makes it exit 0. A staleness check that has only
ever passed is not a check — see
[`../20-development/patterns.md` P1](../20-development/patterns.md#p1--a-guard-is-negative-controlled-or-it-is-not-a-guard).
