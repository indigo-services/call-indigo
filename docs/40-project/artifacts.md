# Artifacts — where generated things live, and what may be deleted

**Kind:** dated · **Owner:** the repo · **Last verified:** 2026-09-27 at `2f009a2`

Two questions this answers, and they are the two that cause real damage:

1. **Is this file tracked, or is it output?** — deleting the wrong one loses work.
2. **May I delete it?** — regenerating the wrong one is impossible.

---

## 1. The classes

| Class | Tracked? | Regenerable? | May be deleted? |
|---|---|---|---|
| **Source** — `src/**`, `index.html`, config | Yes | No | **Never** |
| **Documentation** — `docs/**`, root `*.md` | Yes | No | Only by a deliberate decision |
| **Assets** — `public/assets/images/**`, `images/` | `public/` yes, `images/` no | No | **Never** — see §3 |
| **Generated, tracked** — `src/marketing/chrome-markup.ts` | Yes | Yes | **Never by hand** — regenerate |
| **Generated, ignored** — `dist/`, `.preview/`, `tests/.tmp/`, `*.tsbuildinfo` | No | Yes | Yes, freely |
| **Session state** — `.workbuddy-ai/`, `overview.md` | No | No | `overview.md` yes; **`.workbuddy-ai/` no** |
| **Archive** — `archive/**` | Code and text yes, **binaries no** | No | Only by a deliberate decision |

## 2. Generated, and ignored — delete freely

| Path | Produced by | Why it is safe |
|---|---|---|
| `dist/` | `npm run build` | Every build recreates it |
| `.preview/` | `scripts/_*_sheet.cjs`, `scripts/_credential_row.cjs` | Rendered verification sheets — **generated, never hand-edited** |
| `tests/.tmp/` | `tests/harness.mjs` | Transpiled copies of `src/**/*.ts`, written before import |
| `*.tsbuildinfo` | `tsc -b` | Incremental build cache |
| `node_modules/` | `npm install` | Recreated from the lockfile |

> ⚠️ **Deleting `dist/` breaks `npm run test:only`** — it does not rebuild, so the suite
> will fail or, worse, read a stale tree. If you need to move `dist/` aside, **`mv` it
> rather than `rm` it**: `vite build`'s own `emptyDir` on `dist/` can trip a bulk-delete
> guard.

## 3. Assets — the part that bites

### 3.1 `public/assets/images/` — 95 files, **tracked**

These are the images the site serves. **Never delete one without checking whether a
route renders it.**

> ⚠️ **Never overwrite a photo another route renders.** Several images are shared across
> home, residential and commercial. Swapping one to fix one page changes three.

> ⚠️ **Some image slots are NATURAL-SIZE** — the file's own pixels *are* its rendered
> box. **Read the slot's classes before swapping a file**, or the page moves.

### 3.2 `images/` — 47 files, **gitignored**

The raw media the client supplied (~19 MB). Only the crops and resizes derived from it
ship, and those live in `public/assets/images/`.

**The leading slash in `.gitignore`'s `/images/` is load-bearing.** A bare `images/`
pattern matches a directory of that name at **any depth** — including
`public/assets/images/` — and because gitignore applies later rules last, it would
override the `!public/**` re-include and **silently untrack every shipped image.**

### 3.3 `archive/**` — code and text tracked, binaries ignored

The archive holds past work and reference material. `.gitignore` excludes
`archive/**/*.png`, `*.jpg`, `*.jpeg`, `*.gif`, `*.ico`, `*.bmp`, `*.mp4`, `*.webm` to
keep the repo light.

> **Consequence:** the archived copy of the prototype at
> `archive/v1-prototype/valvoro-prototype/` is **not self-contained** — its images are
> ignored. **Compare against the root `valvoro-prototype/` instead.** See
> [`../60-reference/parity.md`](../60-reference/parity.md).

## 4. Generated, but tracked — the one file to be careful with

| File | Generated by | Rule |
|---|---|---|
| `src/marketing/chrome-markup.ts` | `scripts/_brand.py`, `scripts/_legal.py` | **Never hand-edit.** A needle in the generator that stops matching **fails silently** — the script reports success and writes the un-substituted markup. Edit the generator, run it, then verify the **generated** file. |

## 5. Session state

| Path | What | Rule |
|---|---|---|
| `.workbuddy-ai/` | Project data and memory | **Not a cache. Do not delete.** |
| `overview.md` | A session artifact at the repo root | Gitignored, regenerated each session, **stale the moment it is written**. The durable records are `CHANGELOG.md` and the devlog. |

> **`overview.md` is a third place where project state lives, and it is the least
> reliable of the three.** The documentation plan (Q3) recommends deleting it as a root
> file and letting [`../50-sessions/devlog/`](../50-sessions/devlog/) hold the session
> record.

## 6. Where new generated things should go

**Put it in `.preview/`.** It is already gitignored, and it keeps generated output out
of `docs/` — which matters because
[`../00-meta/conventions.md` §4](../00-meta/conventions.md#4-keep-one-copy) says every
document under `docs/` must appear in the index, and a generated sheet is not a
document.

The **only** exception is a generated thing that is itself a document —
[`../60-reference/routes.md`](../60-reference/routes.md) is the example. It lives in
`docs/` because a reader needs to find it, and it carries a `derived` front-matter line
so nobody hand-edits it.
